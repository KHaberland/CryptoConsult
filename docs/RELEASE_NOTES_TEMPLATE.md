# Крипто-Консультант v1.0.0

Персональный ИИ-ассистент для долгосрочного инвестирования в криптовалюты с управляемым риском.

## Что нового

- Анкета инвестора (10 вопросов)
- Формирование диверсифицированного криптопортфеля
- Отслеживание портфеля в реальном времени
- AI-консультант с рекомендациями
- Алерты при просадке

## Установка

1. Скачайте `CryptoConsult-Setup-1.0.0.exe`
2. Запустите установщик
3. Следуйте инструкциям
4. Для работы потребуются: Python 3.10+, Node.js 18+, OpenAI API ключ

## Требования

- Windows 10/11 (64-bit)
- Python 3.10+ (установите с https://python.org)
- Node.js 18+ (установите с https://nodejs.org)
- OpenAI API ключ
