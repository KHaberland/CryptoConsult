**Дата:** 01.02.2026  
**Статус:** ✅ Реализовано

---

## 1. Общее описание

Переход от автоматической идентификации по `session_id` к идентификации по имени пользователя. Это позволит:
- Пользователю заходить с любого устройства/браузера
- Не терять данные при очистке кэша
- Упростить UX для MVP без регистрации

## 5. Технические изменения

### 5.1. База данных

**Модель InvestorProfile** — добавить поле:
```python
name = models.CharField(
    max_length=100,
    unique=True,  # Имя должно быть уникальным
    verbose_name='Имя пользователя'
)
```

### 5.2. API

**Новый endpoint:**
```
GET /api/profile/lookup/?name=Андрей
```

Возвращает:
- `200` + данные профиля, если найден
- `404`, если не найден

### 5.3. Фронтенд

| Файл | Изменения |
|------|-----------|
| `/src/app/page.tsx` | Главная страница с описанием |
| `/src/app/login/page.tsx` | **Новый** — экран ввода имени |
| `/src/app/welcome/page.tsx` | **Новый** — экран приветствия с анализом |
| `/src/store/sessionStore.ts` | Хранить имя пользователя |

### 5.4. Логика идентификации

```
1. Пользователь вводит имя
2. Запрос GET /api/profile/lookup/?name=...
3. Если 200:
   - Сохраняем session_id из ответа в localStorage
   - Показываем экран приветствия с анализом
4. Если 404:
   - Генерируем новый session_id
   - Запускаем онбординг
   - При создании профиля сохраняем имя
```

## 6. Важные замечания

### Безопасность
⚠️ **Это решение для MVP без регистрации!**

- Любой может ввести чужое имя и получить доступ к данным
- Не использовать для реальных инвестиций с реальными деньгами
- В продакшене нужна нормальная авторизация (email + пароль)

### Коллизии имён
- Если "Андрей" уже существует, новый "Андрей" получит сообщение:
  ```
  Пользователь с таким именем уже существует.
  Пожалуйста, выберите другое имя или добавьте фамилию.
  ```
