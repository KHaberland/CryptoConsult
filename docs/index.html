Крипто-Консультант

Персональный ИИ-ассистент для долгосрочного инвестирования в криптовалюты с управляемым риском

О проекте

Крипто-Консультант — это сервис, который помогает формировать и контролировать криптопортфель на основе ваших целей и толерантности к риску. Приложение не управляет вашими средствами и не совершает сделки — оно даёт рекомендации и аналитику.

После прохождения анкеты (10 вопросов о горизонте инвестиций, сумме, допустимой просадке и опыте) система формирует диверсифицированный портфель. ИИ-консультант отвечает на вопросы, анализирует риски и предупреждает о просадках.

Возможности

Анализ портфеля

Отслеживание распределения активов, рисков и цен в реальном времени. Базовый портфель: BTC, ETH, USDT + 10% альткойны.

Контроль рисков

Алерты при просадке: Warning (80% от допустимого) и Critical (превышение). Рекомендации по ребалансировке и DCA.

AI Консультант

Команды: /status, /recommendation, /risk, /market, /drawdown, /dca, /rebalance. Сервис не управляет средствами.

Требования для работы

  • ОС: Windows 10/11 (64-bit)
  • Python 3.10+ — python.org
  • Node.js 18+ — nodejs.org
  • OpenAI API ключ — для работы ИИ-консультанта

После установки приложения нужно создать файл .env в папке backend и добавить OPENAI_API_KEY=ваш_ключ. Ключ можно получить на platform.openai.com.
